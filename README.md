# Weather App

A simple weather app I built while learning web development. Type in a city name and it shows the current temperature, the weather condition, and the wind speed.

## What it can do
- Search the weather for any city
- Show a message if the city isn't found
- Show a message if you search with an empty box

## Built with
HTML, CSS (Flexbox) and JavaScript

## How it works
The app uses the free Open-Meteo API. It first finds the city's location, then asks for the current weather there. No API key is needed.

## Live demo
https://devkherwal.github.io/weather-app/

## What I learned
This was my first project that uses an API. I learned how to use fetch, async/await and try/catch, and how to show data on a page with JavaScript.
